# PowerPlugin

Minecraft Spigot plugin with `/power` command and 20 powers (including **Metal Jaw**).

## Commands
- `/power add <power> <player>`
- `/power remove <power> <player>`
- `/power awaken <power> <player>` (requires 100% mastery)
- `/power list <player>`

## Metal Jaw
- Lets players consume **any item** by right-clicking with it.
- Grants mastery based on item rarity.
- At 100% mastery it becomes awakenable.

Build with:
```bash
mvn package
```
